# CRUD Farmácia

📦 **CRUD Farmácia** é um projeto para gerenciamento de produtos em uma farmácia, permitindo realizar as operações **Create**, **Read**, **Update** e **Delete** de maneira simples.

## Tecnologias Utilizadas

- 🖥 **Java**: Linguagem de programação principal.
- 🚀 **Spring Boot**: Framework utilizado para a criação da aplicação.
- 🗄 **MySQL**: Banco de dados utilizado para armazenamento das informações.
- 🔄 **JPA/Hibernate**: Frameworks para persistência de dados.
- 🧪 **Insomnia**: Utilizado para testar as APIs criadas.

## Funcionalidades

- ✍️ **Cadastrar produtos**: Permite inserir novos produtos no banco de dados, informando nome, preço, quantidade, etc.
- 👁 **Listar produtos**: Exibe todos os produtos cadastrados.
- ✏️ **Atualizar produtos**: Permite editar as informações de um produto existente.
- ❌ **Excluir produtos**: Exclui um produto da base de dados.
